# Tasks

Especificações de trabalho para agentes e humanos.

## Como criar

1. Copiar `TEMPLATE.md` para `YYYYMMDD-slug.md` (ex.: `20260711-create-client-api.md`).
2. Preencher todas as seções.
3. Listar skills obrigatórias.
4. Implementar só depois do arquivo criado.
5. Ir marcando o checklist durante a execução.

## Regras

- Seguir `AGENTS.md` na raiz.
- Backend: Controller → Service → Repository → Drizzle (classes + nomes padrão).
- Frontend: skill `chakra-ui-builder` antes de qualquer UI.
- Sem regra de negócio em `packages/`.
- Desvio do padrão exige justificativa neste arquivo.
